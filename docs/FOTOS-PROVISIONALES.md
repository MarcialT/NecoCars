# Fotos provisionales

Las siete fotos de `src/assets/images/photos/` (carpetas `services/` y `works/`) son **provisionales**: imágenes con licencia libre de Wikimedia Commons
que sirven para ver cómo queda el diseño hasta que se tomen las fotos reales del taller.

> **No publicar la web con estas fotos.** No son del taller y la sección "Trabajos realizados" las presenta como
> trabajos propios. El cliente pidió fotos reales (ver AGENTS.md §8.1). Las que son CC BY-SA además exigen
> atribución si se publican.

## Cómo reemplazarlas

Copia la foto real en `src/assets/images/photos/` **con la misma carpeta y el mismo nombre** (por ejemplo
`src/assets/images/photos/services/tripoides.jpg`). Si es `.webp` o `.png`, borra antes el `.jpg` del mismo nombre.
No hay que tocar código. Recomendado: WebP, máximo ~1600 px de ancho, tomada de día.
